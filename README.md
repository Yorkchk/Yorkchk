## Featured projects

### [₿ Bitcoin Data Platform](https://github.com/Yorkchk/Bitcoin-data-platform)
End-to-end lakehouse on **Azure Databricks**: CoinGecko data flows through a Medallion architecture (raw → bronze → silver → gold) with Auto Loader and idempotent Delta `MERGE`, is modelled as a **Kimball star schema**, published to Azure SQL, and served by a **FastAPI** service with API-key auth, Redis caching and rate limiting, running in Docker on Azure Container Apps.

`PySpark` `Spark SQL` `Delta Lake` `ADLS Gen2` `Key Vault` `FastAPI` `Redis` `Docker` `Nginx`

### [🩺 MedRational / SWISRA](https://github.com/Yorkchk/MedRational) · [Android app](https://github.com/Yorkchk/MedRational-Android)
A study app built with a medical student association (SCOME Rabat). Students browse, search, preview and share clinical study material, and get push notifications for new files and workshops. Admins manage content and see usage statistics.
- **Backend:** Spring Boot REST API, PostgreSQL, Cloudflare R2 file storage, Amazon SES email, Firebase Cloud Messaging, CI with GitHub Actions
- **Android:** Kotlin + Jetpack Compose, French/English, light/dark themes, tablet layouts

`Java` `Spring Boot` `PostgreSQL` `Kotlin` `Jetpack Compose` `Firebase`

### [🖥️ PC Sur Mesure](https://github.com/Yorkchk/PC_sur_mesure_Mobile_app)
